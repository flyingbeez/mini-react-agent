# mini-react-agent

## 三十秒说清这是什么

**普通 AI**：你问一句，它答一句。它只能"说"。

**这个项目做的 AI**：它会先"动手"，看到结果，再决定下一步，直到把事情办完。

打个比方：

> 你让一个实习生帮你查"北京到上海高铁 4.5 小时是多少分钟"。
>
> 他不会硬算（容易错），而是**掏出手机打开计算器按一下**，
> 看到 270，然后告诉你"是 270 分钟"。
>
> 这个"掏出计算器 → 看结果 → 再回答"的过程，就叫 **Agent**。

**这个项目就是用 300 行代码，把实习生"办事的流程"写出来，让你看清里面每一步。**

不需要联网、不需要注册账号、不需要花钱。clone 下来敲一行命令就能跑。

## 一、先搞懂几个词（很重要，看完再往下）

我把可能看不懂的词都列在这，遇到不懂的就回来查。

| 词 | 说白了就是 |
|---|---|
| **大模型 / AI** | 一个特别会说话的程序。你打字问它，它打字回你。 |
| **Agent（智能体）** | 会"动手做事"的 AI。不只是说，还会用工具、看结果、继续做。 |
| **工具（Tool）** | 给 AI 的一个"按钮"。比如"算数学"按钮、"查天气"按钮。按下去会真的执行。 |
| **循环** | 反复做同一套动作。这里指：想 → 动手 → 看结果 → 再想…… |
| **代码** | 写给电脑看的指令，电脑会照着执行。 |
| **文件 / 文件夹** | 文件就是一份文档；文件夹就是装文档的抽屉。 |

| **运行** | 让写好的程序真的跑起来。 |

## 二、为什么需要"会动手"的 AI？

我问你一个问题：

> "今天北京天气怎么样？"

AI 不知道。因为它的知识是"训练时"学到的，停在过去某个时间点。
它没联网，也没有温度计。

那它会怎么回答？

**它会编一个。** 比如"北京今天晴，25 度"——听起来很像真的，但可能是瞎说的。

这个毛病有个专门的名字，叫 **幻觉**。

### 怎么治？

给它一个"查天气"的按钮。让它先按按钮、拿到真实数据、再回答。

**这就是 Agent 存在的意义：让 AI 从"凭记忆说话"，变成"先查证再说话"。**

## 三、它到底怎么工作的？（这是核心，就这一件事）

整套流程可以画成一句话：

```
        想一下  →  动一下手  →  看看结果  →  再想一下  →  ……  →  能答了，就回答
```

举一个真实的例子。你问：

> "帮我算 (365 × 24 - 100) ÷ 7"

接下来 AI 内部会发生这些事：

**第 1 轮**

- 想：这个要算数，我自己算可能错，先用手边的计算器。—— 这是"想一下"
- 动手：按"计算器"按钮，输入 `(365*24-100)/7`。—— 这是"动一下手"
- 电脑执行：算出 `1237.142857`。—— 这是"看看结果"
- 把结果喂回给 AI

**第 2 轮**

- 想：我已经有结果了，可以回答了。
- 回答："约等于 1237.14"

**结束。**

就这么简单。**整套东西的核心就是这四步在转圈。**

## 四、四个必须知道的"坑"（这是这个项目最值钱的地方）

如果只写上面那个循环，程序跑十分钟就能写出来。真正难的是下面这些情况——
它们不会出现在教科书里，但一旦上线就会出事。

### 坑 1：AI 可能永远停不下来

它会一直按按钮，永远不说答案。

**怎么办**：设一个上限，比如"最多 8 轮，超过就强制停下来"。
就像跟实习生说"你最多试 8 次，还不行就回来找我"。

### 坑 2：AI 卡住了，反复按同一个按钮

它会用一模一样的参数，反复按"计算器"，每次都得到一样的结果，然后继续按。

**怎么办**：记住它按过什么。如果发现它**用同样的参数、按同一个按钮**，
就提醒它一句："你刚才已经试过了，换个办法。" 再不行就强制停止，并把已经拿到的信息交出来。

> 这一条是这个项目里最值得讲的经验：
> **光设上限不够。**上限只是让它"慢慢死"，
> 得让它**知道自己卡住了**，它才会换策略。

### 坑 3：按钮坏了（工具报错）

比如按"查天气"按钮，结果网络断了。这时候如果直接崩溃，整个程序就挂了。

**怎么办**：不要崩。把"按钮坏了"这件事本身，当成一条信息告诉 AI。
AI 看到"按钮坏了"，就会自己想办法（换个按钮，或者告诉你不行）。

### 坑 4：按钮吐出来一大堆东西

比如"查资料"按钮返回了 10 万字的文章。全部喂给 AI，会把它撑爆（还特别费钱）。

**怎么办**：太长就截断，只留前面一部分，并标注"这里被截断了"。

## 五、跑起来看看

先确认电脑上有 Python（一个编程语言，这个项目是用它写的）。
在本项目文件夹里打开命令行，敲：

```bash
python run_tests.py
```

这会跑 103 个"自动检查"。**全部通过**就说明代码是好的。

然后敲：


**这个输出就是最好的教学材料，建议对着它看上面的第三节和第四节。**

> 放心：这两个命令都**不需要 API Key、不需要联网、不花钱**。

## 八、这个项目故意没做什么（实话实说）

1. **不会"流式输出"**。也就是它想完了才一次性给你，不像 ChatGPT 那样一个字一个字往外蹦。
2. **没有多轮对话记忆**。你问完一句，它不记得上一句说了什么。
3. **同一轮里只能一个一个按钮按**，不能同时按好几个。
4. **只支持两种让 AI 说话的方式**，覆盖面有限。

把这些写出来不是谦虚。**知道自己做的东西边界在哪，比说"我做完了"更有用**——
面试官问起来你也答得上。
